Intisari Materi — Sebelum Mulai

  • Pertidaksamaan linear dua variabel: bentuk ax + by ≤ c, ax + by ≥ c, ax + by < c, atau ax + by > c (x, y variabel).
  • Garis batas: ganti tanda pertidaksamaan dengan "=" menjadi ax + by = c. Garis penuh untuk ≤ / ≥, garis putus-putus untuk < / >.
  • Menentukan daerah: uji satu titik (misal O(0,0)) ke pertidaksamaan; jika bernilai benar, daerah yang memuat titik itu adalah penyelesaiannya.
  • Daerah penyelesaian sistem = irisan (perpotongan) seluruh daerah tiap pertidaksamaan; titik pojoknya penting untuk mencari nilai maksimum/minimum fungsi objektif.
